# src/tests/ (Infraestructura de Pruebas Automatizadas)

## Responsabilidad
Esta carpeta organiza la suite de pruebas del ERP/POS dividida por alcance y propósito:
1. **`unit/`**: Pruebas unitarias puras.
2. **`integration/`**: Pruebas de integración con servicios y base de datos.
3. **`e2e/`**: Pruebas de extremo a extremo de flujos de usuario.
4. **`mocks/`**: Proveedores de datos sintéticos estandarizados.
