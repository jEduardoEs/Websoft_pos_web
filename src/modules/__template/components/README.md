# components/ (Presentación Atómica)

## Responsabilidad
Alojar los componentes de React visuales secundarios específicos de este módulo (filas de tabla, botones de acción local, tarjetas resumen, pestañas).

## Reglas
- No deben hacer `fetch()` ni interactuar con la base de datos.
- Reciben sus datos y manejadores de eventos mediante props.
