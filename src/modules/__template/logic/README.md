# logic/ (Dominio y Casos de Uso)

## Responsabilidad
Contener las funciones puras que implementan las reglas de negocio del módulo (ej. cálculos de subtotales, desglose de impuestos, algoritmos de comisiones).

## Reglas
- Código de TypeScript puro sin dependencias de React, JSX, DOM ni frameworks HTTP.
- Fácilmente testable de forma unitaria.
