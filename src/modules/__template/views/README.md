# views/ (Vistas Principales)

## Responsabilidad
Contener los componentes de vista principal del módulo que son consumidos por las páginas de Next.js App Router (`src/app/`).

## Reglas
- Consumen los Custom Hooks locales de `hooks/` para obtener datos y funciones de acción.
- Ensamblan los componentes visuales de `components/` y `src/ui/`.
